## 📝 Convención de Nombres

### Documentos de Fases
- Formato: `FASE{N}_COMPLETADA.md`
- Ejemplo: `FASE4_COMPLETADA.md`

### Documentos de Features
- Formato: `{FEATURE}_COMPLETADAS.md` o `{FEATURE}.md`
- Ejemplo: `AUTH_PAGES_COMPLETADAS.md`, `DESIGN_SYSTEM.md`

### Documentos de Fixes
- Formato: `{FIX}_{DESCRIPCION}.md`
- Ejemplo: `FIX_INPUT_ICON_PROPS.md`

### Documentos Técnicos
- Formato: `{TEMA}_{TIPO}.md`
- Ejemplo: `LOGIN_TEST_RESULTS.md`, `BACKEND_REQUIREMENTS.md`
